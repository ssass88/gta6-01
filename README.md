An open-world crime game in the spirit of GTA 6, set in the sun-soaked, neon-lit criminal underworld of Vice City.

Built autonomously by AI agent @ssass88 for the [make.fun](https://make.fun) gta6-01 competition.

---

## Features

- **Massive 2.5D Open World**: Multi-block urban playground featuring Downtown skyscrapers, Port Vice industrial cargo docks, and luxury villa estates on Starfish Island.
- **Dynamic Pseudo-3D Engine**: Canvas-based 2.5D building extrusion, cast shadows, depth-sorted multi-layer rendering, and dynamic lighting.
- **Vehicles & Physics**: 6 unique driveable models (Viper GT exotic, Stallion 77 muscle car, Sentinel executive cruiser, Mule heavy cargo, Police Cruiser, SWAT Enforcer). Full acceleration, drifting, handbrake, and collision physics.
- **Traffic & Pedestrian AI**: Living city with lane-following traffic, collision avoidance, and panic-reactive pedestrians.
- **Wanted Star System (1-5 Stars)**: Escalate your criminal notoriety from patrol units to high-speed road blocks and armored SWAT interceptors.
- **Procedural Web Audio Soundscape**: 100% synthesized engine RPM pitch shifting, tire screeches, sirens, weapon blasts, and 3 custom synthwave radio stations.
- **Multi-Stage Missions & Story**: Dynamic pager/phone contracts, cargo drops, safehouse takeovers, and cash rewards.
- **Full HUD & Radar**: Circular minimap with player heading, vehicle blips, police radar, wanted stars, health/armor bars, and speedometer.
- **Offline & Zero Dependencies**: Vanilla ES modules running 100% offline in any modern desktop browser.

## Quick Start

Serve static files locally:
`ash
node serve.ts
`
Open http://localhost:8080 in Chrome to play!

### Controls

| Action | Key / Input |
|---|---|
| **Move / Drive** | WASD or Arrow Keys |
| **Sprint / Nitro** | Shift |
| **Enter / Exit Car** | F or Enter |
| **Handbrake** | Space |
| **Aim & Shoot** | Mouse Aim + Left Click |
| **Switch Weapon** | 1, 2, 3, 4, 5, 6 or Mouse Wheel |
| **Radio Station** | R |
| **Pause / Resume** | P or Escape |
